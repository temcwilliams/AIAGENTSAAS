# Agent Meadow repository workflow

Read `PROGRESS.md` when starting or resuming project work. The user requested a living Markdown record of progress.

Update `PROGRESS.md` as meaningful implementation, verification, migration, deployment, or user-decision changes occur. Keep current status and blockers accurate, and append significant outcomes to the dated history. Distinguish implemented code from deployed code, mocked tests from real inference, and pending actions from completed ones. Preserve useful earlier history.

Never place passwords, API keys, database connection strings, bridge tokens, or private account-setup/sign-in files in the progress log or repository. Record secret configuration only by its purpose and completion status.

Documentation-only changes do not require application redeployment. Current user instructions take precedence over this workflow.
